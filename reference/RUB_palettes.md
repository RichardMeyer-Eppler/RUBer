# RUB color palette

This is a color palette using the colors defined by the corporate
design.

## Usage

``` r
RUB_palettes
```

## Format

An object of class `list` of length 12.

## References

https://www.ruhr-uni-bochum.de/cd/

## Examples

``` r
RUB_palettes["discrete_5"]
#> $discrete_5
#>      green   green_60 light grey    blue_40       blue 
#>  "#8DAE10"  "#BBCE70"  "#E7E7E7"  "#99AEBF"  "#003560" 
#> 
```
