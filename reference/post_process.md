# Post process Word file created with officedown

Post process Word file created with officedown

## Usage

``` r
post_process(old_path, new_path, overwrite = FALSE)
```

## Arguments

- old_path:

  String with path to Word file created by officedown

- new_path:

  New path for edited Word file

- overwrite:

  Boolean, overwrite files if they exist. If this is `FALSE` and the
  file exists an error will be thrown.
